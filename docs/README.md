# Zombie Factions Documentation

This directory contains the canonical design and validation documentation for Zombie Factions.

- `REQUIREMENTS.md` — normative behavior and MVP acceptance criteria.
- `ARCHITECTURE.md` — proposed runtime model and boundaries.
- `TESTING.md` — validation plan.
- `ROADMAP.md` — current and future work.
- `PZ_MODDING_POLICY.md` — mandatory repository compliance rules.
- `RELEASE_CHECKLIST.md` — release gate.
- `adr/` — architecture decisions.
- `spikes/` — focused implementation research and evidence.

The README at repository root is descriptive. When behavior, design, roadmap, or validation details conflict, the corresponding document in `docs/` is authoritative.
