# Architecture decision records

ADRs preserve consequential technical decisions that had realistic alternatives. Routine implementation details belong in [`../ARCHITECTURE.md`](../ARCHITECTURE.md).

## Index

- [`ADR-001 — Zombie combat authority`](ADR-001-zombie-combat-authority.md) — **Accepted**. Defines server policy/damage authority and owner-client pursuit/presentation responsibilities.
- [`ADR-002 — Direct acquisition replaces mob-and-leader targeting`](ADR-002-direct-acquisition.md) — **Accepted**. Each zombie acquires its own target; records the measurement that reversed the v0.0.18 decision, and audits the code the mob layer leaves behind.

Use a numbered filename such as `ADR-002-short-decision-name.md`. Record context, decision, consequences, alternatives considered, and supporting evidence.
