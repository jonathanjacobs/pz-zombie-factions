# ADR-000 — Record Format

Status: Accepted

## Context

Zombie Factions depends on engine-behavior research and may require decisions that affect compatibility, multiplayer authority, and performance.

## Decision

Each significant architecture decision will be recorded as an ADR with:

- Status: Proposed, Accepted, Superseded, or Rejected;
- Context;
- Decision;
- Consequences;
- Evidence/validation references where applicable.

## Consequences

Implementation choices remain traceable to the evidence available when they were made.
