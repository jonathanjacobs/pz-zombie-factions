# Changelog

Initial repository foundation.

- established Build 42 mod package structure;
- defined Vanilla/default zombie faction concept;
- defined directional `FRIENDLY`, `NEUTRAL`, and `HOSTILE` relationship model;
- documented integration with existing Project Zomboid player factions;
- added architecture, testing, roadmap, ADR, research-spike, and compliance framework;
- added minimal faction registry/relationship API skeleton;
- no zombie-targeting or zombie-vs-zombie combat behavior is claimed in this version.
